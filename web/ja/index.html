Ear Number

EN

片耳がどれだけよく聞こえるかを表し、オージオグラムに戻すこともできる 3 桁の数字です。大きいほど良く、999 は健康な若い耳、000 はまったく聞こえないことを表します。

最も近いよくあるパターン：数字が記録するもの あなたの点（左 X、右 O）：ドラッグできます

点を上下にドラッグするか、グラフをクリックして点を置きます。点を動かすと、線は 50 のよくある聴力パターンのうち最も近いものに切り替わります。そのパターンと聞こえの程度が数字に記録される内容なので、線は点の真上ではなく、点の近くを通ります。グラフの上ほど聴力が良いことを表します。キーボードでは Tab で点に移動し、矢印キーを使います。

聴力検査の結果を入力する
結果はどこから得たものですか？

オージオグラムは、各周波数で聞こえた最も小さな音を示します。周波数は上部に左から右へ並び、音の大きさは縦に下へ進みます。0 が上にあり、数字が大きい（聞こえが悪い）ほど下になります。控えをもらっていない場合は、病院に頼んでください。

  • 右耳は丸（O、通常は赤）、左耳はバツ（X、通常は青）を読み取ります。ある周波数に三角（右）や四角（左）があれば、そちらを使います。マスキングをした同じ検査です。
  • < > [ ] は無視してください。骨導という別の検査です。
  • 記号に付いた矢印は、検査した最大の音でも反応がなかったことを表します。あなたの閾値はそのレベルより先にあります。示されたレベルか、希望すればそれより高い値を入力してください。100 を超える値は 100 として扱います。
  • 250、750、1500 Hz の値は不要です。上のグラフをクリックして各点を置くこともできます。

各値を印刷どおり dB HL で入力します。3 kHz と 6 kHz は任意で、結果になければ空欄のままにします。職場の健診の多くは 6 kHz までです。8 kHz がない場合は、6 kHz の値をコピーするよう提案します。

反応なし（多くは NR や矢印）と記された値は、検査した最大のレベルでも何も聞こえなかったことを表します。そのレベルか、希望すればそれより高い値を入力してください。100 を超える値は 100 として扱います。

Apple の「ヘルスケア」で「聴覚」、次に「オージオグラム」を開き、検査を開くと各耳・各周波数の値が見られます。ほかのアプリも通常は似たグラフや一覧を表示します。

スマートフォンやイヤホンは病院の機器のように校正されていないため、数字には E（推定）を付けます。Apple の検査は約 85 dB HL までの難聴しか測れません。値がその上限にある場合、その周波数の聴力はさらに悪いかもしれず、希望すればより高い値を入力できます。

Ear Number について

なぜ聴力に数字が必要なのか？

視力には「1.0」のような数字があります。聴力にはオージオグラムがあります。約 7 つの周波数で耳が感じ取れる最も小さな音を示すグラフです。耳の状態をよく表しますが、自分のものを覚えている人はいませんし、機器に入力するのも面倒です。「軽度」「中等度」の難聴という言い方は、何かを調整するには大ざっぱすぎ、どの周波数が影響を受けているかもわかりません。

Ear Number は覚えて伝えられるほど短く、大きいほど聴力が良いという順序になっていて、音楽プレーヤーやイヤホン、補聴器アプリがグラフに戻せるだけの情報を持っています。

数字の読み方は？

1 人につき 2 つの数字があり、左耳が先、そのあとに入力ミスをソフトウェアが見つけるためのチェック数字が続きます：705 688 4。それぞれの数字は 2 つの問いに答えます。

どれだけ聞こえるか。目盛りは 50 ずつの区切りで進み、1 区切りは耳の平均閾値の 5 dB にあたります。平均は会話に最も重要な周波数を重視して求めます。1000 から数字を引いて 10 で割ると、その平均が dB で 5 dB 以内の精度で得られます。

数字平均閾値ふだんの言葉で
800–99920 dB 未満正常な聴力
650–79920〜35 dB軽度難聴
500–64935〜50 dB中等度難聴
350–49950〜65 dBやや高度難聴
200–34965〜80 dB高度難聴
050–19980〜95 dB重度難聴
000–04995 dB 以上ほとんど、またはまったく聞こえない

どんな型か。50 の区切りの中で、位置は 50 の典型的な形の 1 つを選びます。全周波数で平坦、高音が早く・遅く下がる、4 kHz 付近のくぼみ、などです。この部分は形を表すもので、順位ではありません。905 と 940 は型の違う同じくらい良い耳で、950 は 949 より 1 段階良い耳です。

  • 2 つの数字が 50 以上離れていれば、大きいほうがこの尺度でより良い耳です。それより近いときは、どちらが大きいかから結論を出さないでください。
  • 聴力検査は完全には再現できず、数字も同じです。再検査で下 2 桁が変わることはよくあり、隣の区切りに移ることもあります。100 以上の変化を本当の変化と考えてください。

000、E、N の意味は？
  • 000 はその側が聞こえない、または耳がないことを表します。
  • E（例：456E）は、数字が病院ではなく、スマートフォンやイヤホンでの自己測定によることを表します。こうした数字は精度が粗くなります。
  • N はその耳を測定しておらず、値を仮定したことを表します。通常はもう一方の耳の値を写したものです。

数字はどこから来たのか？

数字のもとになる表は、米国国民健康栄養調査（NHANES）に含まれる 6 歳から 80 歳超までの 29,061 耳の聴力検査から学習しました。作成時に除外しておいた耳では、数字から戻したグラフと実測のグラフの差は約 5 dB で、同じ耳をもう一度検査したときの差とほぼ同じです。

これは何ではないか？

Ear Number が表すのは聴力閾値だけです。診断ではなく、難聴の原因については何も示さず、聴力評価の代わりにもなりません。騒音の中で言葉をどれだけ聞き取れるか、どの程度の音が大きすぎるか、耳鳴りは表さず、500 Hz 未満や 8 kHz 超についても何もわかりません。

ジョンズ・ホプキンス大学が推進する Hearing Number とは別物です。そちらは dB で表す 1 つの平均値で、小さいほど良いものです。Ear Number の「どれだけ」の部分はそれに近い値です：(1000 − Ear Number) / 10。

入力した内容はどこかに送られますか？

すべてブラウザの中で行われます。入力やドラッグした内容がどこかに送られることはありません。コピーしたリンクは数字を # の後ろに入れます。アドレスのこの部分はブラウザがサーバーに送りません。共有リンクはふつうのリンクで、それらのサービスのものはこのページに一切読み込まれず、あなたが投稿を選んだ内容だけが渡ります。
